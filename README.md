# Mo-(b)logs for Mosms

## Intro

This is a repository for my mo-(b)logs which are mainly concerned about some book notes or ideas(insights), where for theme I used Simple Texture now.

My own website is also build by github pages which can be seen from [Homepage](https://mosms.github.io/), while this mologs' website is [Mologs](https://mosms.github.io/Mologs), you are free to check or learn from them. 

## About the Mo-logs

These logs will be colorful with many different types, where you can see them as my own note about the "life" itself, but I believe they must be not bad to read.
